# Fitness Nutrition Tracker

## Project Overview

Fitness Nutrition Tracker is a .NET Blazor web application created as a group project for CSE 325. The application helps users organize basic fitness and nutrition tracking in one place. Users can access a dashboard, nutrition features, workout tracking, profile management, goals, progress, and documentation.

## Main Features

- Professional dashboard and navigation structure
- Nutrition Diary and food registration support
- Workout tracking with add, edit, and delete functionality
- User profile form with validation
- Goals planning page
- Progress summary page
- Documentation and final demo guide
- SQLite database support for nutrition data
- Seeded nutrition data using JSON processing

## Technology Stack

- .NET 8
- Blazor Server
- C#
- Entity Framework Core
- SQLite
- Razor Components
- GitHub
- Azure DevOps

## Application Pages

- `/` Dashboard
- `/nutrition-diary` Nutrition Diary overview
- `/register-food` Food registration page
- `/workouts` Workout tracking
- `/profile` User profile
- `/goals` Goals
- `/progress` Progress
- `/documentation` User guide and demo flow
